## Wave · WiFi Analyser 1.0.1

First public preview for **Android, macOS, Windows and Linux**. All features are free. No account required; optional donations do not unlock features.

### Choose your download

| Platform | Asset | Install / requirements |
| --- | --- | --- |
| Android | `wave-wifi-analyser-android.apk` | Universal release APK. Allow installation from your download app when Android asks. Grant precise Location access and enable Location services for live scans. |
| macOS | `wave-wifi-analyser-macos.zip` | Extract and move the complete app into Applications. macOS 12+. Ad-hoc signed, **not Developer ID signed or notarized**; macOS may block opening. |
| Windows | `wave-wifi-analyser-windows-x64.zip` | Extract the **whole ZIP** and run `wifi_analyser.exe`. Requires compatible x64 Windows and latest [Microsoft Visual C++ v14 x64 runtime](https://aka.ms/vc14/vc_redist.x64.exe) (14.51 or newer). Unsigned; Windows may warn. Enable Location consent for WiFi APIs where required. |
| Linux | `wave-wifi-analyser-linux-x64.tar.gz` | Ubuntu 24.04 x64 baseline; GTK 3, libnl 3/libnl-genl, modern glibc/libstdc++, NetworkManager and a managed nl80211 WiFi adapter. Extract the whole archive and run `wifi_analyser`; optional `install-launcher.sh` adds a user launcher. **Ubuntu 22.04 is incompatible.** |

**Windows and Linux have not been tested on real WiFi hardware.** Native builds and automated checks do not verify real-world RF scans, drivers, permission dialogs or daily desktop use. Treat these ports as experimental. macOS lacks notarization; this preview is not an App Store, Microsoft Store or Play Store release. No iOS or web download is included.

### Features

- Live WiFi scanning on Android/macOS and experimental Windows/Linux bridges; explicit demo mode for exploration.
- Connection overview, signal history, searchable networks, favourites and private aliases.
- 2.4/5/6 GHz spectrum views and explainable channel-overlap rankings.
- Local room recordings/comparisons and reviewed, privacy-first summary/CSV export; Linux saves reviewed files to a chosen folder.
- Responsive mobile/desktop layouts, light/dark/system themes, keyboard navigation, reduced motion and original animated onboarding.

### Measurements and privacy

OS/driver permissions and scan throttling apply. Unknown channel width and per-AP freshness remain disclosed; channel rankings are overlap heuristics, not throughput/noise measurements. Desktop scan completion does not prove every AP was observed anew. No packet capture, router configuration or geographic location collection.

These downloads are ordinary Flutter release builds and **do not receive Shorebird updates**. Install future full releases from this page. Android uses a persistent distribution signing key; users of older development APKs with a different signature must export any needed data before uninstalling them to install this release.

Compare downloaded files with `SHA256SUMS`. Keep every desktop bundle's libraries and assets together. Source, platform details and testing limits are in the repository README and `docs/`.
