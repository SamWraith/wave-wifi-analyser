**No macOS binary in this release.** Source hardening removes injected debugging access, enables hardened runtime and separates Flutter/Shorebird entitlements. The local ad-hoc hardened app fails dyld library validation at startup. Developer ID signing, notarization and a successful native launch are required before a replacement binary can be distributed. No system protections were disabled.

Windows/Linux remain experimental: automated build and feature tests do not establish real WiFi hardware, driver, permission-dialog or daily-use reliability. Android emulator checks do not prove physical RF behavior. No iOS/web download is included.

### Changes

- Signal-guided router finder tracks one BSSID, shows relative signal changes, resets on frequency changes and labels stale, missing or simulated observations. It cannot determine a compass bearing or exact router position.
- Android excludes app data from legacy backup and Android 12+ cloud/device transfer and disables cloud backup. Manufacturer behavior can vary; earlier backups are not erased.
- Sharing checks selection validity before preparation and handoff. Cancelled/stale preparation and dismissed shares remove owned files. Other handoffs retain temporary files for up to 24 hours before cleanup on the next startup/share, with a 16-operation cache limit. Settings can explicitly clear temporary exports. Receiving apps may retain independent copies.
- Production Android signing fails closed; unsigned F-Droid and development builds require explicit modes. Current-source private home paths removed, with recurrence checks.
- GitHub Actions and Flutter source use immutable revision checks; release source/tag checks prevent mixed-source drafts.

Existing connection overview, accepted signal history, searchable networks, favourites/aliases, spectrum/channel rankings, room comparisons, reviewed exports, responsive layouts, themes, keyboard navigation, reduced motion and animated onboarding remain available.

### Privacy and verification limits

WiFi data is stored locally under OS protections without app-level encryption. Desktop filesystem/account backups may include it. Export identifiers and labels remain opt-in; aliases are never exported. No geographic coordinates or WiFi passwords are collected. Overlap scores do not measure throughput or noise; desktop completion IDs do not prove per-AP freshness.

These are ordinary Flutter builds with no Shorebird updater. Install future full releases from GitHub. Android upgrades retain the existing certificate; differently signed development installations cannot upgrade in place.

Verify exact assets against `SHA256SUMS`. Full remediation details and limits: [security remediation report](https://github.com/SamWraith/wave-wifi-analyser/blob/v1.0.2/docs/SECURITY_REMEDIATION_2026-10-17.md). Source and automated checks do not establish notarization or physical WiFi accuracy.
